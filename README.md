# Papilla Tesserete

Mock interattivo con tre proposte visive per Osteria Papilla. L’HTML, gli stili, lo script e le immagini sono in `public/`.

Per Netlify, importa il repository. La cartella di pubblicazione è già impostata su `public` in `netlify.toml`. Lascia vuoto il comando di build.

Per vedere il mock in locale, apri `public/index.html` nel browser.
